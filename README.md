# WATransChat

**WATransChat** is a **WhatsApp browser translation extension** specially designed for **cross-border e-commerce customer service**, helping you greatly improve communication efficiency and customer satisfaction.

It can **automatically detect the customer’s country, language, currency, and local time**, enabling agents to quickly understand customer backgrounds and provide more professional, personalized service.

---

## ✨ Key Features

* 🌍 **Automatic customer background detection**: Instantly displays country, language, currency, and local time
* 🔄 **4 powerful translation engines**: Supports **200+ languages** with **no text or usage limits**
* 💬 **Real-time translation**: Automatically translates both **sent and received** messages for truly **barrier-free communication**
* ⚡ **Quick actions**:

  * Instantly start chats with unknown numbers
  * One-click insertion of common phrases
  * Save customer language preferences
* 🖥️ **Seamless integration**: Fully compatible with WhatsApp Web — no window switching required
* 📱 **Responsive design**: Perfect for both solo agents and cross-border teams

# Installation Guide

## Android Mobile Version

Download **WATransChat.apk** directly to your phone and install it.

## Chrome Extension Installation

1. Download **WATransChat.zip** to your computer and extract it.
2. Open the Chrome extensions page (type `chrome://extensions/` in the address bar and press Enter).
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** on the left and select the extracted folder.
5. Installation complete.

## Microsoft Edge Extension Installation

1. Download the **WATransChat.crx** file.
2. Open the Edge extensions page (type `edge://extensions/` in the address bar and press Enter).
3. Enable **Developer mode** on the left side.
4. Drag the downloaded **WATransChat.crx** file into the browser to install.

## Other Browser Installation

Simply drag the **WATransChat.crx** file into your browser to install.

## How to Log In via QR Code

* When logging in, make sure to use **split-screen** or **floating window** mode.
* Otherwise, the QR code will refresh when switching windows, preventing a successful scan.
